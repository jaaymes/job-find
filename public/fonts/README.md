# Fontes dos PDFs

Todas sob a SIL Open Font License 1.1 (arquivos `LICENSE-*.txt` mantidos sem alteração).

- `JFSans-*.ttf`: versão modificada da Source Sans 3 (instância estática 400/700 + subconjunto latino). A licença reserva o nome "Source"; por isso, conforme a cláusula 3 da OFL, a derivada foi renomeada para "JF Sans". Licença: `LICENSE-SourceSans3.txt`.
- `JFGrotesk-*.ttf`: versão modificada da IBM Plex Sans (instância estática 400/700 + subconjunto latino). A licença reserva o nome "Plex"; por isso a derivada foi renomeada para "JF Grotesk". Licença: `LICENSE-IBMPlexSans.txt`.
- `SourceSerif4-*.ttf`: Source Serif 4 (instância + subconjunto). Sem nome reservado.
- `Inter-*.ttf`: Inter. Sem nome reservado.

Os arquivos são gerados por `scripts/subset-fonts.sh`.
